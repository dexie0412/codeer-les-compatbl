Wat is code eigenlijk?

0 – 5 min
Doel: je weet wat code is en waarom computers precies moeten krijgen wat je bedoelt.

Een computer kan snel rekenen, maar hij kan niet zelf nadenken. Hij doet alleen wat jij opschrijft, stap voor stap. Dat opschrijven noemen we code, en de mensen die dat doen heten programmeurs.

Denk aan een recept: als je schrijft “doe iets met de eieren”, dan weet niemand wat er moet gebeuren. Bij code moet het dus heel precies.

🥪 Mini-opdracht (in tweetallen, 2 minuten)

Jouw partner is een robot en doet alleen letterlijk wat je zegt. Leg uit hoe je een boterham met pindakaas maakt. Je mag maar korte opdrachten geven, zoals “pak het mes”.

💡 Wat merk je? Als één stap ontbreekt (“open de pot”), loopt alles vast. Dat noemen programmeurs een bug. Fouten maken hoort erbij!

HTML: het skelet van een website

5 – 15 min
Doel: je maakt zelf een webpagina met een kop, tekst en een lijstje.

HTML vertelt de browser wat er op de pagina staat. Je gebruikt daarvoor tags: een begin-tag en een eind-tag, met je tekst ertussen.

<h1>Ik ben een grote kop</h1>
<!-- ↑ begin-tag   ↑ tekst   ↑ eind-tag (met een /) -->
TagWat doet het?
<h1>Grote kop (er is ook h2, h3…)
<p>Een stukje tekst (paragraaf)
<ul> + <li>Lijstje met bolletjes
<b>Dikgedrukte tekst

✏️ Probeer het zelf

Links staat de code, rechts zie je meteen het resultaat. Verander de tekst en kijk wat er gebeurt!

🎯 Opdrachten

🐞 Werkt het niet? Controleer of elke begin-tag een eind-tag heeft, met een /.
3

CSS: maak het mooi

15 – 23 min
Doel: je geeft je pagina kleuren en een eigen stijl.

HTML is het skelet, CSS is de kleding. Met CSS bepaal je kleuren, lettergrootte en achtergrond. De opbouw is altijd hetzelfde:

h1 {                 /* wie wil je veranderen? */
  color: hotpink;     /* eigenschap: waarde; */
  font-size: 48px;
}

🎯 Opdrachten

🎨 Kleurnamen zoals red, teal, gold werken meteen. Zoek er gerust meer op!
👩‍🏫 Docenttips
  • Vergelijk met een poppetje in Roblox/Minecraft: de pagina (skelet) en de skin (CSS).
  • Veelgemaakte fout: de puntkomma ; vergeten. Laat leerlingen elkaars code controleren.
4

JavaScript: laat het reageren

23 – 35 min
Doel: je laat een knop iets doen en je gebruikt een variabele.

Met HTML en CSS blijft een pagina stil staan. JavaScript maakt hem levend: er gebeurt iets als je klikt, typt of beweegt.

📦

Variabele

Een doosje met een naam waarin je iets bewaart, zoals je naam of je score.

🔘

Event

Iets wat gebeurt, bijvoorbeeld “er wordt op de knop geklikt”.

🧩

Functie

Een setje opdrachten met een naam, dat je kunt uitvoeren wanneer je wilt.

let score = 0;           // variabele: doosje "score" met 0 erin
score = score + 1;       // nu zit er 1 in

✏️ Een klik-teller

Klik op de knop rechts. Daarna ga je de code aanpassen!

🎯 Opdrachten

👋 Nog één: een begroeting

⚠️ In code is hoofdletter ≠ kleine letter: score en Score zijn voor de computer twee verschillende dingen.
👩‍🏫 Docenttips
  • Je hoeft function en getElementById niet uit te leggen: “dit zoekt het vakje met die naam op de pagina”. Het gaat om het idee dat code kan reageren.
  • Laat leerlingen voorspellen wat er gebeurt voordat ze een getal aanpassen.

Python en andere talen

35 – 40 min
Doel: je ziet dat er veel programmeertalen zijn en dat de ideeën hetzelfde blijven.

Er bestaan honderden programmeertalen. Elke taal heeft zijn eigen “spelling”, maar de ideeën (variabelen, herhalen, beslissen) zijn overal gelijk. Wie er één snapt, leert de rest sneller.

  console.log("Hallo!");
}

Jouw eigen mini-project

40 – 47 min
Doel: je combineert wat je geleerd hebt tot een eigen pagina.

Maak een pagina “Alles over mij” met alles wat je vandaag geleerd hebt. Je mag de editor hieronder gebruiken.

  1. HTML: een kop met je naam, een alinea over jezelf en een lijstje.
  2. CSS: kies een achtergrondkleur en een kleur voor je kop.
  3. JavaScript: maak een knop die iets leuks doet, zoals een tekst veranderen of een teller ophogen.

✅ Checklist

👩‍🏫 Docenttips
  • Loop rond en stel vragen in plaats van de oplossing te geven: “Wat verwacht je dat er gebeurt?”
  • Laat snelle leerlingen een tweede knop maken, of de kleur van de pagina laten veranderen bij een klik.
  • Leerlingen kunnen hun code kopiëren naar een Word-/Notities-bestand als ze die willen bewaren.
